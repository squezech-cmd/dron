# 🛩️ Dron — боевой FPV-дрон для Minecraft 1.20.1 (Fabric)

Мод добавляет **быстрый военный квадрокоптер-камикадзе** и **пульт управления** с
полноценным военным HUD в стиле FPV-очков.

| | |
|---|---|
| 🎮 Версия игры | Minecraft **1.20.1** (Fabric) |
| ⚙️ Загрузчик | Fabric Loader 0.15+ |
| 📦 Зависимость | [Fabric API](https://modrinth.com/mod/fabric-api) |
| ☕ Java | 17+ |

---

## Как играть

1. Получите **«Пульт боевого дрона»** — он лежит в креативной вкладке **«Дрон»**.
2. Возьмите пульт в руку → **ПКМ**: дрон вылетает вперёд, и вы *сразу* оказываетесь за штурвалом.
3. Управление:

| Клавиша | Действие |
|---|---|
| **W / S** | тяга вперёд / назад |
| **A / D** | крен влево / вправо |
| **Пробел** | набор высоты |
| **Shift** | снижение |
| **R** | отозвать дрон (мягкая посадка, без взрыва) |
| **ЛКМ** | подорвать дрон вручную |

4. Врезались в блок, моба, игрока или воду — **боевая часть детонирует**.
5. Если дрон улетел дальше **260 блоков** от точки запуска или разрядился — он
   самоликвидируется (взрыв слабее, чем при таране).

Дрон **быстрый**: максимальная скорость около **30 блоков/сек** (108 км/ч),
корпус маленький (0.55 × 0.55 блока), а моторы постоянно жужжат —
звук слышен всем вокруг и усиливается с ростом скорости.

## Что внутри

### Дрон
* Кастомная процедурная модель: карбоновый корпус, турель камеры, боевая часть
  под брюхом с предупреждающими полосами, четыре вращающихся винта и посадочные
  полозья.
* Реалистичная (для Minecraft) физика квадрокоптера: инерция, сопротивление
  воздуха, крен на скорости, авто-зависание при отпущенных клавишах.
* Постоянное жужжание моторов + громкий взрыв при подрыве.
* Дрон неуязвим к огню, не тонет, не толкается, но **взрывается от любого**
  урона (стрелы, мечи, другие взрывы).

### HUD (в стиле военной FPV-системы)
* Зелёный «фосфорный» интерфейс с полосами развёртки и виньетками.
* Лента компаса, искусственный горизонт, прицел-бракеты.
* Приборы: **скорость**, **высота**, **дистанция**, **батарея**, **уровень сигнала**.
* Индикатор боевого взвода с пульсирующей анимацией.
* Предупреждения «НИЗКИЙ ЗАРЯД» / «ПОТЕРЯ СИГНАЛА» с миганием.
* Индикатор **REC** в углу, как на реальном FPV-видео.
* Ванильный хотбар, сердца и прицел скрываются во время полёта.

## Сборка из исходников

```bash
./gradlew build
# готовый jar: build/libs/dron-1.0.0.jar
```

> Требуется JDK 17. Репозиторий также содержит GitHub Actions workflow:
> каждый пуш в ветку автоматически собирает мод, а готовый jar кладётся
> в артефакты сборки (**Actions → Build Mod → Artifacts → dron-mod**).

## Установка

1. Установите **Fabric Loader** для Minecraft 1.20.1.
2. Положите [Fabric API](https://modrinth.com/mod/fabric-api) и `dron-1.0.0.jar`
   в папку `.minecraft/mods`.
3. Запустите игру с профилем Fabric.

## Структура проекта

```
src/main/java/com/squezech/dron/
├── DronMod.java              — общий entrypoint
├── entity/CombatDroneEntity  — логика дрона, физика, детонация
├── item/DroneRemoteItem      — пульт управления
├── network/DronNetwork       — сеть (телеметрия HUD + отзыв дрона)
├── registry/                 — предметы, сущности, звуки
└── mixin/                    — Shift не сбрасывает пилота, доступ к прыжку

src/client/java/com/squezech/dron/client/
├── DronModClient             — клиентский entrypoint
├── hud/DroneHud              — боевой HUD
├── render/                   — модель и рендерер дрона
└── mixin/                    — FPV-камера и скрытие ванильного HUD
```
