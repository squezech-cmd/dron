# 🛩️ Dron — боевой FPV-дрон для Minecraft 1.20.1 (Fabric)

Быстрый **военный дрон-камикадзе** с пультом управления, жужжанием моторов и
полноценным **FPV-HUD** в стиле очков оператора. Маленький (0.5 × 0.45 блока),
резкий (до 36 блоков/с ≈ 130 км/ч) и подрывается при столкновении.

## Установка

1. Установите **Fabric Loader** для Minecraft 1.20.1.
2. Положите в `.minecraft/mods`:
   * `fabric-api-*.jar`;
   * **`dron-1.0.0.jar`** — готовый файл лежит в
     [последнем релизе](https://github.com/squezech-cmd/dron/releases/latest).
3. Запустите игру с профилем Fabric.

---

## Как играть

1. Возьмите **«Пульт боевого дрона»** — он лежит в креативной вкладке
   **«Боевой дрон»**.
2. **ПКМ** с пультом в руке → дрон вылетает вперёд, и вы сразу оказываетесь за
   штурвалом (камера — на носу дрона, руки с пультом скрыты).
3. Управление:

| Клавиша | Действие |
|---|---|
| **W / S** | тяга вперёд / назад |
| **A / D** | снос влево / вправо |
| **Пробел** | набор высоты |
| **Shift** | снижение |
| **Мышь** | прицел (нос дрона следует за взглядом) |
| **ЛКМ** | подрыв боевой части на месте |
| **R** | безопасный отзыв (дрон складывается, взрыва нет) |

4. Врезались в блок, моба, игрока или воду — **детонация**. Боевая часть
   ломает блоки и наносит урон по площади (радиус ≈ 3.6).
5. Дрон **неуязвим к огню и контактному урону**, но взрывается от попадания
   стрелы/меча и от чужого взрыва.

### Расходники и ограничения

* **Батарея** — 3 минуты полёта. Села → самоликвидация (слабый взрыв).
* **Радиус связи** — 280 блоков от точки запуска. Вышли за радиус → сигнал
  падает до нуля и дрон самоликвидируется.
* **РЭБ**: маяки в радиусе 22 блоков глушат видеосвязь (HUD краснеет,
  появляется шипение помех и «ПОМЕХИ · EW JAM»).
* **Форсаж**: если рядом с точкой запуска стоит блок **магмы**, дрон получает
  форсаж (+28% тяги, +12% скорости) — «модуль полётного контроллера».

## HUD оператора

* Зелёный «фосфорный» интерфейс с развёрткой, виньетками и рваной строкой
  аналогового канала.
* Прицел-бракеты с маркером цели, искусственный горизонт, лестница тангажа,
  индикатор крена.
* Лента компаса с текущим курсом.
* Приборы: **скорость**, **высота**, **дистанция до оператора**, **батарея**,
  **сигнал** и индикатор **взрывателя**.
* Предупреждения «НИЗКИЙ ЗАРЯД», «ПОТЕРЯ СИГНАЛА», «ПОМЕХИ · EW JAM»,
  «ВЫХОД ЗА РАДИУС».
* Индикатор **REC** и таймер полёта в углу, как на реальном FPV-видео.
* Серые полосы здоровья/хотбар/прицел на время полёта скрываются.

## Как это устроено

* **Сервер — авторитет**: считает физику 20 раз в секунду, проверяет
  столкновения, расход батареи, РЭБ и радиус связи, применяет взрыв.
* **Клиент — предсказание**: пилот интегрирует тот же полёт каждый кадр, поэтому
  картинка плавная, а сервер лишь подтверждает финальную точку удара
  (межсерверная интерполяция растянута с 3 до 5 тиков).
* **Ввод** идёт отдельными пакетами `dron:input` / `dron:look` (20 Гц),
  телеметрия — `dron:telemetry` (10 Гц). Клиент без пакетов управления
  автоматически «отпускает» газ.
* **Сеть**: `dron:input`, `dron:look`, `dron:recall`, `dron:detonate`,
  `dron:telemetry`.
* **Звук** — свой набор Vorbis OGG: зацикленное жужжание (громкость и высота
  зависят от скорости), взлёт, детонация, писк пульта и шипение помех.
  Все звуки сгенерированы скриптом `tools/gen_sounds.py`, текстуры —
  `tools/gen_textures.py` (воспроизводимо, без бинарных исходников).

## Сборка из исходников

```bash
./gradlew build          # готовый jar: build/libs/dron-1.0.0.jar
```

Нужен **JDK 21** для сборки (Loom 1.17), байткод при этом Java 17.
CI (GitHub Actions) на каждый пуш собирает мод и прогоняет **дымовой тест
выделенного сервера** под Mixin — чтобы поймать ошибки загрузки до релиза.

## Структура проекта

```
src/main/java/com/squezech/dron/
├── DronMod                     — общий entrypoint
├── entity/CombatDroneEntity    — полёт, столкновения, детонация, РЭБ
├── item/DroneRemoteItem        — пульт управления
├── network/                    — пакеты ввода, прицела, телеметрии
├── registry/                   — предметы, сущность, звуки, вкладка
└── mixin/PlayerMixin           — Shift не сбрасывает пилота

src/client/java/com/squezech/dron/client/
├── DronModClient               — клиентский entrypoint
├── DroneFlightModel            — предсказание полёта каждый кадр
├── hud/DroneHud                — военный FPV-HUD
├── render/                     — модель и рендерер дрона
├── sound/                      — зацикленное жужжание и помехи
└── mixin/                      — FPV-камера, скрытие рук и ванильного HUD

tools/                          — генераторы текстур и звуков
```
